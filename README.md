# Corporate Finance & Sales Intelligence Copilot

An enterprise AI workspace for Finance and Sales intelligence, analytics,
document retrieval, and evidence-backed management reporting.

## Project Status

Development: Initial engineering foundation

## Architecture

- Frontend: React + TypeScript + Vite
- Backend: FastAPI
- Structured analytics: SQL + Python
- Document intelligence: Hybrid RAG
- Orchestration: LangGraph where justified
- Database: PostgreSQL
- Vector database: Qdrant
- Development infrastructure: Docker Compose
